# E-CPU

E-CPU is created because me, the creator of ENux got bored. Its main goal is to have an emulated 6502 processor usable in your browser

The 6502 emulator is written in C++ (check src/) and compiled to js and wasm with em++

Go to https://extras.emirpasha.com/E-CPU to test it for yourself

Note: AI was used to enlighten me about the 6502 specs and debugging. This project wasn't vibe coded
